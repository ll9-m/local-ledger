# 本地记账本

一个装进手机就能用的极简记账 App。纯前端 PWA，零依赖零构建，**数据只存在你自己的手机里**，不联网、不上传、无账号。

- 在线地址：https://local-ledger-31478.app.workbuddy.host/
- 形态：Web App，可「添加到主屏幕」后像原生 App 一样全屏运行、断网可用

---

## 目录结构

```
local-ledger/
├── index.html     首页：明细 / 统计 / 我的 三个 Tab
├── add.html       记一笔（新建 / 编辑记录）独立页面
├── cat.html       类别管理（增删改名换色排序）独立页面
├── manage.html    筛选与批量清理独立页面
├── app.css        全部样式 + 三套主题变量表
├── store.js       数据层：记录 / 类别 / 筛选 / 主题 / 工具函数
├── sw.js          Service Worker：离线缓存
├── manifest.json  PWA 清单
└── icon.svg       应用图标
```

> 测试脚本 `smoke-test.js` 在**上一级目录**（工作区根目录），不属于运行时代码。

## 本地运行

Service Worker 与 PWA 安装要求 HTTP(S) 环境，直接双击 `index.html` 用 `file://` 打开会失效。起一个静态服务即可：

```bash
cd local-ledger
python -m http.server 8000
# 浏览器打开 http://localhost:8000/
```

手机访问需要局域网地址（`http://<电脑IP>:8000/`），手机与电脑连同一个 Wi-Fi。

## 装到手机上

1. 手机浏览器打开在线地址；
2. **iPhone**：Safari 底部「分享」→「添加到主屏幕」；
3. **安卓**：Chrome 右上角菜单 →「添加到主屏幕 / 安装应用」；
4. 之后从桌面图标进入，无地址栏、无浏览器界面，断网也能记账。

工作区根目录的 `手机扫码打开记账本.png` 是带二维码的引导图，扫码可省去手输网址。

## 功能

### 明细（首页）
- 月份切换 + 本月结余 / 收入 / 支出汇总，以及与上月的对比趋势；
- 按日期分组的记录列表，点任意一条看详情，可编辑或删除；
- **筛选**按钮跳 `manage.html`，筛选生效时顶部出现可点掉的筛选标签，笔数显示「命中 / 总数」；
- 右下角 `+` 进入记一笔。

### 统计
- **日**：当日三栏、与近 30 天日均的对比条、当日分类排行；
- **月**：12 个月趋势折线（canvas）+ 分类占比排行；
- **年**：12 个月收支双柱图、年度分类排行、月度结余明细、月均支出。

### 我的
- 外观主题：毛玻璃 / 浅色 / 深色；
- 类别管理（跳 `cat.html`）；
- 数据：导出 CSV、导入 CSV、载入示例数据、清空全部数据。

### 记一笔（`add.html`）
- 金额走手机输入法（`inputmode="decimal"`，自动过滤非法字符、最多两位小数）；
- 类别一行横向滑动选择，点「全部」在本页展开完整网格；
- 日期、备注；保存后自动回首页并刷新。

### 类别管理（`cat.html`）
- 支出 / 收入分开管理，可新建、改名、换图标、换色、拖动排序、删除自定义类别；
- 内置类别只能改名换色，不可删除；删除自定义类别时被引用的记录会自动归入「其他」。

### 筛选与批量清理（`manage.html`）
- 条件：类型、类别、起始 / 截止日期、关键字（备注或类别名）；
- 结果列表可勾选，支持全选与**批量删除**（二次确认）；
- 「应用」把条件带回首页；不需要时点「重置筛选」。

## 技术说明

**无构建**：没有 npm、没有打包器，改完文件刷新即可。所有页面共享 `store.js` 与 `app.css`，页面间用 `location` 跳转 + `localStorage` 脏标记同步。

**数据键（localStorage）**

| 键 | 内容 |
|---|---|
| `local_ledger_v1` | 记录数组 |
| `local_ledger_cats_v1` | 类别（支出 / 收入） |
| `local_ledger_theme` | 当前主题 `glass` / `light` / `dark` |
| `local_ledger_filter` | 当前筛选条件 |
| `local_ledger_dirty` | 时间戳，首页据此重渲染 |

**记录结构**

```js
{ id, type: 'expense'|'income', amount: 12.5, cat: 'food', note: '午饭', date: '2026-09-01', ts: 1690000000000 }
```

约定：`amount` 恒为**正数**，方向由 `type` 决定；展示时收入 `+¥x`、支出 `-¥x`，汇总与排行都按正数口径。

**跨页同步**：`add.html` / `cat.html` / `manage.html` 改完数据写 `local_ledger_dirty`，首页在 `pageshow` / `visibilitychange` 里检测该标记后重新加载并渲染（解决 bfcache 恢复首页时脚本不重跑的问题）。

**主题**：`app.css` 里全部颜色走 CSS 变量（`--w*`/`--s*`/`--l*`/`--bf*`），三套值挂在 `html[data-theme]` 上；canvas 图表通过 `cssv()` 读变量，切主题后重绘即换色。

## 几条刻意的设计决策

改动这些地方前，建议先知道为什么：

1. **凡是要打字的功能都做成独立页面，不用弹层。** 弹层里的输入框会和手机软键盘抢屏幕，任何 JS 补偿都追不上系统键盘动画，表现为上挤、卡顿、底部闪一下。记一笔、类别管理、筛选因此都是独立文档页面，靠浏览器原生顶起输入框，代码里没有任何键盘高度补偿。
2. **筛选页的类别选择器不用原生 `<select>`。** 原生下拉会一次性展开 18 个类别，面板超高引发整页重排和闪烁。改为页面内限高网格：3 列 × 2 行，一屏露 6 个，其余滚动。
3. **批量操作工具条放在列表上方，不是屏幕底部。** 底部会被软键盘顶掉。
4. **汇总卡始终按整月计算**，不受筛选条件影响，避免「本月结余」的语义被筛选改变；筛选只影响明细列表。
5. **首次打开是空的**，不再灌演示数据。想看效果在「我的」里手动点「载入示例数据」。老版本里留下的演示数据会在启动时被一次性清理（判定很保守：仅当所有记录备注都命中演示全集时才清，不会误删真实记录）。

## 发布

改完代码要更新线上时：

1. 把 `sw.js` 里的 `CACHE` 版本号 +1（例如 `local-ledger-v15` → `v16`），否则老手机会一直用旧缓存；
2. 发布 `local-ledger/` 目录（入口 `index.html`）；
3. 用 `curl -o /dev/null -w "%{http_code}"` 抽查线上文件是否 200。

线上页面是网络优先，通常刷新即可拿到新版；拿不到时下拉刷新一次。

## 已知限制

- 数据只在本机浏览器里，清缓存 / 换手机会丢，重要数据请用「导出 CSV」备份；
- 单币种、无预算、无周期记账；
- 图标是 SVG，iOS 添加到主屏幕后会走 maskable 裁切。
